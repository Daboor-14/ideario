# Ideario

A local-first visual workspace for notes, images, links and creative projects.
Available in English and العربية on Windows, Mac and iPad.

## Download

[**Download the latest version**](https://github.com/Daboor-14/ideario/releases/latest)

| Device | File or link |
| --- | --- |
| Windows | `Ideario-Setup-<version>.exe` — installer with automatic updates |
| Windows portable | `Ideario-Portable-<version>.exe` |
| Mac with Apple silicon | `Ideario-<version>-arm64.dmg` |
| Mac with Intel | `Ideario-<version>-x64.dmg` |
| iPad / web | [Open Ideario](https://daboor-14.github.io/ideario/) |

On iPad, open the link in Safari, then choose **Share → Add to Home Screen**.
Your boards stay on your device. Use Settings → Back up to save a copy.

## تحميل البرنامج

حمّل النسخة المناسبة لجهازك من [صفحة الإصدارات](https://github.com/Daboor-14/ideario/releases/latest).
على الآيباد افتح [Ideario](https://daboor-14.github.io/ideario/) في Safari، ثم اختر مشاركة ← إضافة إلى الشاشة الرئيسية.
